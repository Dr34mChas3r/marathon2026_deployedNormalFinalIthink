# Виконані домашні завдання

## 1. Backend (.NET) — рівні 1, 2 і 3

- **Рівень 1 (передумова до рівня 2):** API списку учасників групового pre-order з їхніми стравами, сумами та статусом подання.
- **Рівень 2:** отримання ID owner-сесії та підтвердження консолідованого замовлення; перевірки власника, статусів і помилкових станів.
- **Рівень 3:** видалення гостьової сесії власником і повернення оновленого snapshot групи.

## 2. Frontend — рівні 1, 2 і 3

- **Рівень 1:** екран Owner Review зі списком кошиків, статусами, підсумками та адаптивним відображенням.
- **Рівень 2:** інтеграція з мок-API, власний кошик, консолідований pre-order та підтвердження відправлення.
- **Рівень 3:** інтеграція зі справжнім API, оновлення статусу й кошиків кожні 15 секунд, ручне оновлення та обробка помилок фонової синхронізації.
- **Бонус до рівня 3:** видалення гостя з підтвердженням і оновленням даних групи.

## 3. Автоматизоване тестування

- Реалізовані та перевірені frontend-тести домашки й тести backend-функціоналу.
- `npm run test:hw`: **63 тести пройшли**.
- `dotnet test`: **164 тести пройшли**.
- TypeScript-перевірки (`tsconfig.app.json` і `tsconfig.spec.json`) та production build пройшли. Збірка показує наявні попередження про розмір bundle і залежності, без помилок.
